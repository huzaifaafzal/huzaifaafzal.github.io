Case study / Developer platform

Self-service EMR, with teardown you can trust.

At Systems Limited, assigned to Visionet Systems Inc., I built the Jenkins/CloudBees and Terraform workflows that let Regeneron’s users provision and tear down their own AWS EMR clusters, with validation, approvals, and an ownership check before anything is deleted.

Context

Regeneron was moving its Apache Spark and Hadoop workloads from EC2 and Hortonworks Data Platform to AWS EMR. I assessed the existing data lake setup, contributed to the proof of concept, the migration architecture, and validation, and evaluated cost and job-execution tradeoffs for the client.

Once workloads ran on EMR, the next problem was access: cluster provisioning was manual. The goal was to let users create and remove clusters themselves without giving up control over the resources.

What I built

  • A reusable Terraform module that replaced manual provisioning of EMR on EC2, covering cluster prerequisites, S3 resources, AWS networking, and autoscaling.
  • Self-service Jenkins/CloudBees pipelines for provisioning and teardown. Shell scripting turned the form inputs into Terraform variables, and Groovy, Python, and the AWS CLI handled validation and automation.
  • Approvals, job submission, and email notifications that reported the cluster name, cluster ID, and S3 log location.
  • Terraform state stored in and retrieved from S3, so each pipeline run managed the right deployment.

The guardrail that mattered most

Self-service creation is the easy half. Self-service deletion is where a platform earns trust. Before any teardown, the pipeline compared the Jenkins user who made the request with the AWS resource tags on the target cluster. Only if the requester owned that cluster did it retrieve that deployment’s Terraform state from S3 and remove the cluster and the resources created for it, including its S3 bucket where applicable.

That one check meant users could clean up after themselves without being able to delete someone else’s work by mistake.

Outcome

  • Users provisioned and tore down EMR clusters themselves, with validation and approvals built into the pipeline.
  • The move to EMR improved autoscaling and reduced infrastructure costs for the client.
  • The reusable Terraform module replaced manual cluster provisioning.
